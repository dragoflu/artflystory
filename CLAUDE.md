# Сайт-визитка художника

## Контекст проекта
Сайт-портфолио для художника (мама пользователя). Цель — визитка с работами, контактами и стилем под личный бренд.

## Пользователь
- Не веб-дизайнер, нужно объяснять решения простым языком
- Предпочитает конкретные действия без лишнего overhead
- Работает в VS Code + Claude Code CLI

## Материалы
- Яндекс.Диск: https://disk.yandex.ru/d/9tm2yNqxoiMqzQ (фото работ, референсы, материалы)
- Визуальный референс: уточнить (первый приложенный скриншот оказался не тем)

## Структура директории
```
основной/
├── assets/
│   ├── images/      # фото работ, фото автора
│   └── fonts/       # шрифты
├── docs/
│   └── plans/       # дизайн-доки и планы реализации
├── src/             # исходный код сайта
└── CLAUDE.md        # этот файл
```

## Стек (предстоит выбрать)
Варианты обсуждаются: статический HTML/CSS/JS, Astro, или конструктор (Tilda/Webflow).

## Скиллы — что есть и чего не хватает
### Есть:
- `canvas-design` — создание визуального дизайна в PNG/PDF
- `brainstorming` — проработка идей перед реализацией
- `writing-plans` — написание планов реализации
- `dispatching-parallel-agents` — параллельная работа агентов

### Нужно написать (отсутствуют):
- `frontend-web-design` — HTML/CSS/JS паттерны, адаптивный дизайн, типографика
- `site-performance` — оптимизация изображений, Core Web Vitals, lazy loading
- `seo-basics` — мета-теги, структурированные данные, sitemap

## Рабочий процесс
1. Собрать материалы с Яндекс.Диска в `assets/`
2. Определить стек
3. Написать дизайн-doc в `docs/plans/`
4. Реализовать
