# Бриф: сайт ARTFLYSTORY

**Анна Флит** — художник-дизайнер, архитектор. Член Евразийского Художественного Союза и Союза Архитекторов. Основатель бренда Art_flystory (с 2019). Выставки: Москва, Пекин, Байонна.

- **Слева:** декоративная композиция из круглых рамок с работами + золотые кольца
- **Центр:** слоган + кнопки (типа "Начать" / "Перейти в галерею")
- **Справа:** форма обратной связи "ДАВАЙТЕ ПОГОВОРИМ" (Имя, Email, Сообщение, кнопка)
